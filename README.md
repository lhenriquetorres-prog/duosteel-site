# Site Duosteel

Site estático (HTML + CSS + um pequeno JS, sem framework) gerado a partir do design da Duosteel no Claude.

- Espanhol na raiz (mercado paraguaio), português em `/pt/`
- Fotos em WebP (`img/obras/<obra>/NN-800.webp` para os cards, `NN.webp` para ampliar)
- Botões de WhatsApp com mensagem pronta; formulário de orçamento abre o WhatsApp com os dados preenchidos
- Publicado pelo GitHub Pages a partir da branch `main`
